# GSP1337 - Prototype apps in Google AI Studio

This lab has no Cloud Shell. Everything happens in Google AI Studio, under BUILD in the left menu. The prompts and names to type are in copy blocks.

## Known lab traps/bugs (read first)

1. Wrong account. Open AI Studio in the Incognito window with the lab's student account.
2. Drive access comes first. The checks read the record AI Studio keeps in Google Drive, so do the History > Allow Drive access step before anything else. If you ever see "Failed to store recent Application", do that step again.
3. Do not remix or edit the gallery apps in Tasks 1 and 2. Remixing needs a paid API key that the student account does not have. Just open them and look around.
4. Never click Upgrade and never set up billing, whatever window offers it. Close it with its X.
5. "Failed to generate API key" can pop up while your app builds. Ignore it as long as the build keeps running.
6. If the Code assistant stops with "Permission denied", wait a few seconds and click Retry. If that does not help, send the same prompt again.
7. Building the app takes up to 8 minutes. Do not rename the app or send another prompt until the assistant has finished. If a "Resolve conflicts" window appears, click Accept.
8. The app name must be exactly AI Travel Itinerary Generator. The checker lags: if a check fails, wait 30-60 seconds and click again.

## Task 1. Explore a pre-built app

1. In the left menu click History, then click Allow Drive access. Pick the student account and grant access.
2. In the left menu, under BUILD, click Gallery.
3. Click the All apps tab and find ChatterBots (Ctrl+F in the browser and type the name below finds it fast). Click it.

```text
ChatterBots
```

4. If the browser asks for the microphone, click Allow.
5. The app opens with the Code assistant on the left and a live Preview on the right. Try a preset ChatterBot in the Preview.
6. Click Code and open a file such as App.tsx to see how the app is built.

## Task 3. Build and modify an app from a prompt

Build it:

1. In the left menu, under BUILD, click New app.
2. Paste this into the main prompt bar and click the Send arrow:

```text
Create an app that generates a 3-day travel itinerary for a city. The app should have an input field for the city name. The output should be a structured plan with days, times, and activities, displayed in a clean format. The app must work without an API key or any external API calls: include built-in 3-day itineraries for Rome, Paris, Tokyo, and New York, and show a friendly message for other cities.
```

3. Wait for the build to finish (up to 8 minutes, see traps 5 and 6).
4. In the Preview, type the city below in the input field and press Enter. You should see a 3-day plan with days, times and activities.

```text
Rome
```

Add a feature:

5. In the Code assistant field at the bottom left, paste this and click the Send arrow:

```text
Add a packing list section below the itinerary that suggests 5 items for the selected city, using built-in data only (no API calls).
```

6. Wait until the assistant has finished. Generate the Rome itinerary again: a packing list with 5 items should appear under it.

Rename it (only after the assistant has finished):

7. Hold the pointer over the app name at the top, click the pencil icon, type exactly the name below, leave the description as it is, and click Save. If "Resolve conflicts" appears, click Accept.

```text
AI Travel Itinerary Generator
```

## Task 4. Download, publish and view your apps (no check button in the lab text)

1. Click Code, then Export > Download as .zip file. The app's source code downloads to your computer.
2. In the top toolbar click Publish and read the options. Do not finish publishing.
3. Click the Google AI Studio logo (top left), then under BUILD click My apps.
4. Open the By you tab. Your travel app is listed there. A new name can take a few minutes to show.
